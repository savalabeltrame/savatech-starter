# 🏪 Savatech Starter

Sistema de gestión comercial para pequeños negocios:
- Caixa PDV con carrito, descuentos y tickets
- Gestión de productos con stock y vencimientos
- Clientes con historial de compras
- Cierre de caja y relatórios
- Roles: administrador y cajero

## Ejecutar localmente

pip install -r requirements.txt
streamlit run app.py
